6. Escalate if stuck (free) | Prajavani: grievance gets a portal ID and an Action Taken Report. Mandal-level Prajavani every Monday 10 AM to 1 PM at the Mandal Parishad office (since Aug 2026). === TABLE 2
Part | Choice | Why
Frontend | Next.js (React) with Tailwind, mobile-first, Telugu and English | You already built a React demo. Works on any phone browser
Backend | Next.js API routes (serverless) on Vercel | No server that sleeps. Functions start in about a second when called. AgentFoundry has one-click deploy to Vercel
Database | Neon Postgres (free) | Neon says compute pauses after 5 minutes idle but wakes in a few hundred milliseconds and never pauses the project. Supabase free pauses after 7 days of low activity and needs a manual resume, so avoid it
Login | Simple staff login (for example NextAuth with email or a passcode per home) | Keeps real resident data private
AI | A free-tier LLM API with tool calling, plus a rules fallback | Check current free limits first. If AI fails, rules still work
Two deployments | demo (fake data, public link) and pilot (real data, login) | Judges get a live link; residents stay private
